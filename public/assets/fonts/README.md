# Font Files Required

Place the following `.woff2` files in this directory:

1. **Recoleta-Black.woff2** — Recoleta Black (weight 900) — used for all headings (H1–H6)
2. **MyriadVariableConcept-Regular.woff2** — Myriad Variable Concept Regular (weight 400) — body text
3. **MyriadVariableConcept-Black.woff2** — Myriad Variable Concept Black (weight 900) — bold body text, buttons

These are commercial/licensed fonts. Obtain them from the designer's asset package.
